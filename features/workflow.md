# Workflow

Devin Session Board archives AI coding sessions, risk notes, review summaries, open questions, delivery receipts, and team handoff evidence.

## Repeatable Flow

1. Import Devin session links, summaries, owners, and delivery goals.
2. Review risk notes, tests, blockers, and open questions.
3. Group sessions by customer, repository, release, and reviewer.
4. Export searchable delivery evidence and handoff reports.

## Output Mindset

The useful artifact is not a marketing claim. It is evidence that a reviewer can inspect, export, and compare later.
